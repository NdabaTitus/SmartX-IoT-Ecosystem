# Smart-X IoT Ecosystem

Part 1 submission for PROG7312/w - Advanced Application Development.

## Projects

- **SmartX.Gateway** - ASP.NET Core Web API (backend)
- **SmartX.WPF** - WPF Dashboard (frontend)

## How to Run

1. Open the solution in Visual Studio 2022
2. Set both projects to start together (Solution > Configure Startup Projects > Multiple)
3. Press F5
4. In the dashboard, click "Connect to Gateway"
5. Click "Generate Test Data" to see telemetry flow
