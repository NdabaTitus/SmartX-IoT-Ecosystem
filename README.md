\# Smart-X IoT Ecosystem



A hybrid Internet of Things (IoT) ecosystem designed to monitor and manage

distributed environments such as hydroponic farms, automated real estate

utility trackers, and smart grid installations.



\*\*Part 1 — Advanced Application Development (PROG7312/w)\*\*  

The Independent Institute of Education (IIE)



\---



\## Architecture Overview



| Project | Type | Purpose |

|---------|------|---------|

| \*\*SmartX.Gateway\*\* | ASP.NET Core Web API | Backend: receives, validates, stores telemetry |

| \*\*SmartX.WPF\*\* | WPF Desktop App | Frontend: monitoring dashboard |
